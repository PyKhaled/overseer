Quick start

Add Overseer to an existing Compose file, mount the Docker socket, then expose the dashboard on port 8765.

services:
  overseer:
    image: ghcr.io/pykhaled/overseer:0.2.0
    restart: unless-stopped
    ports:
      - "8765:8765"
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock

Start the project and open http://localhost:8765.

docker compose up -d
Protect access to Overseer

Overseer has no built-in authentication, and Docker socket access is effectively administrative access to the host. Run it only on a trusted network and put authentication and TLS at a trusted reverse proxy before allowing remote access.
